# Full Context vs RAG 실험 결과 (자동 채점)

> **실험용 합성 데이터 기준.** 실제 Steam 뉴스로 일반화하지 않는다. 정답은 자동 채점이며 수동 확인 표본으로 보완한다.
> 지연 = 모델 로딩 제외(total − load) p50 / p95 초. A의 cold = 캐시가 빈 첫 요청, reuse = 같은 코퍼스 앞부분 캐시 재사용.
> 본 실행 A의 cold는 구간 첫 질문 1개뿐이다(캐시 비우기용 짧은 요청이 효과가 없어 2·3번째는 reuse로 다시 분류). A-cold = 모델을 내렸다 올려 캐시를 비운 추가 측정(구간당 5문제).
> **qwen3:4b는 비교 불가**: Thinking 모델이라 `think: false`에도 추론을 이어 가 출력 한도(1024)에서 잘리고 '답:' 줄이 없는 응답이 많다. 이때 채점이 추론 문장까지 보게 되어 정확도가 부풀 수 있다. 결론은 bonsai-2:9b로만 낸다.
